講師用 全画面マップ

ファシリテーターが合宿中に各画面へ飛ぶための一覧です。店舗ジャーニー／利用者ジャーニー／講師用に分け、各画面がどの詰まりを体現するかを併記しています。

📍
これは講師用ナビです（受講生体験の入口ではありません）。 受講生は index.html から「お店として始める／お客さんとして予約する」に入って導線を体感します。講師はこのページから任意の画面へ直接ジャンプし、画面投影・解説に使ってください。模範解（収益の答え合わせ）は 収益サマリー にあります（受講生には伏せる）。
🏠 トップ index.html 📊 収益サマリー（模範解） 受講生入口：お客さん側 → 受講生入口：お店側 →
① 店舗ジャーニー（供給側・PC管理画面） A-00 → A-01 → A-02 → A-03 ⇄ A-04 / A-05
A-00入口
店舗 新規登録（サインアップ）
「お店として始める」の入口。登録＝初月課金・トライアルなし（月額12,000円）。
詰まり：導線の起点（次のA-01で詰まる）
../admin/A-00_signup.html
A-01詰まり①
初期設定（オンボーディング）
店名／写真／住所電話／営業時間7行／メニュー複数／料金／スタイリスト複数／定休日。
詰まり①：入力項目が多く・進捗表示なし・CTAが何ステップ目か不明で完了まで遠い → 設定完了で離脱
../admin/A-01_onboarding.html
A-02公開
店舗ページ公開
設定完了後に店舗ページを公開する画面。公開した店舗ページ（U-01）への確認導線あり。
詰まり：健全（A-01を抜けた店舗の出口）
../admin/A-02_publish.html
A-03詰まり②
管理ダッシュボード
店舗オーナーのホーム。キャンセル通知（トースト／バッジ）が目立つ。サンプル予約 6/25(水)14:00 カット／山田 花子 様。
詰まり②：キャンセル通知が目立ち、店舗のうんざり感 → 3ヶ月目の早期解約の文脈
../admin/A-03_dashboard.html
A-04店舗側
予約一覧
店舗側の予約テーブル。A-03のサイドナビから相互遷移。同じサンプル予約が店舗側にも見える。
詰まり：②の文脈の裏付け（キャンセル行が並ぶ）
../admin/A-04_reservations.html
A-05店舗側
請求・プラン
月額12,000円のサブスク請求画面。A-03のサイドナビから相互遷移。
詰まり：収益①（店舗サブスク）の発生点
../admin/A-05_billing.html
② 利用者ジャーニー（需要側・スマホ） U-01 → U-02 → U-03 → U-03b → U-04（再予約は U-04 → U-02）
U-01入口
公開店舗ページ（田中美容室）
受講生「お客さん側」の入口。メニューと料金（カット¥4,400／カラー¥8,800ほか）。「予約する」→ U-02。
詰まり：予約導線の入口（次のU-02で詰まる）
../user/U-01_store.html
U-02詰まり③a
予約フォーム
メニュー／日付／時間／スタイリスト指名(必須)／名前／電話／要望(必須)／アンケート(必須)。
詰まり③a：項目が多くスクロールが長い＋送信CTAが下線青文字のテキストリンク風でボタンに見えない・固定フッターなし → 訪問→予約で離脱
../user/U-02_form.html
U-03詰まり③b
予約確認
「予約時のお支払いは不要・来店時に施術料金をお支払い」の後払い案内。確定ボタンと並んで「キャンセル」が目立つ。
詰まり③b：金銭コミットなしで気軽にキャンセルできる構造 → 来店確定率が落ちる（当日キャンセル）
「キャンセル」→ U-01に戻る／「予約を確定する」→ U-03b
../user/U-03_confirm.html
U-03b完了
予約完了
予約確定の完了画面。「マイページ」→ U-04 への導線。
健全：確定後の正常な着地点
../user/U-03b_done.html
U-04対照（健全）
マイページ
次回予約・予約履歴。「次の予約を取る」→ U-02 へスムーズに戻れる。
健全（対照）：リピート導線はスムーズ＝詰まりがないことを見せる対照画面
../user/U-04_mypage.html
