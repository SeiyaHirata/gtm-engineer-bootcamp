GTM Bootcamp 受講生教材

各ワークに入る前に、対応するステップの解説を読む。答えは書いていない。自分で出す。

  • 0目的今日のゴールと進め方
  • 1セットアップ環境を再現して、全員が同じデータに立つ
  • 2サービスとファネルを整理するサービスを読み、流れ(ファネル)を自分で1枚に描く
  • 3SQLで詰まりを特定するデータで「どこで落ちているか」を名指す
  • 4改善点を洗い出す詰まりごとに施策を出す（質より量）
  • 5工数×インパクトで優先度二軸に並べて、着手順を決める
  • 6提案数字→課題→施策→投資対効果→結論
  • 7持ち帰り明日、自分の現場でやること
