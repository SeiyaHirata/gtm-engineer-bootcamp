公開 71%・2ヶ月 90% は健全。漏れは 設定完了 56%（★①） と 3ヶ月継続 50%（★②） の2か所。

② 課題

漏れは2つ（公開・2ヶ月は健全）

★① 設定完了

56% 登録500 → 設定完了280

オンボーディングが重い。設定項目が多く、最初の設定で半分が脱落する。

★② 3ヶ月継続

50% 2ヶ月178 → 3ヶ月89

2ヶ月→3ヶ月で半減。根本はユーザー側＝予約が回らないこと。

健全　公開71%・2ヶ月継続90%は業界の目安どおり。手を入れる必要はない。

D 解約クーポン（②対策）

3ヶ月継続 +14店 / ROI 34倍

数字だけ見ると、きれいに伸びて見える。

これは対症療法

予約が回らない根本原因（ユーザー側）を直さないと、クーポンで一度引き止めても翌月以降にまた解約する。

だから店舗側は①に投資する

店舗側でやるべきは①設定完了の改善。継続の土台を作る方が、ROIの数字以上に効く。

解約クーポンは「後回し」。第1=ステップガイド / 第2=未完了リマインドで設定完了を先に伸ばす。
